# Görsel Programlama - Görüntü İşleme Laboratuvarı

Bu depo, Görsel Programlama dersi kapsamındaki görüntü işleme laboratuvar çalışmalarını ve projelerini içermektedir.

## 📁 Proje Yapısı

- **[`goruntu_arayuz/`](./goruntu_arayuz/)**: Python, OpenCV, NumPy ve Tkinter kullanılarak geliştirilmiş genişletilebilir masaüstü görüntü işleme arayüzü.
  - Görüntü Açma (Türkçe karakter ve BGR desteği)
  - Renkli ↔ Gri Dönüşümleri (Teorik bilgi kaybı açıklamaları ile)
  - 10x10 Blok Ekleme (NumPy dilimleme ve iç içe for döngüsü mantığı)
  - Kayıpsız PNG Kaydetme
  - Modüler mimari (her hafta yeni buton/metot eklenebilir)
- **[`Hafta2/`](./Hafta2/)**: Hafta 2 laboratuvar çalışmaları, temel OpenCV uygulamaları ve alıştırmaları.

---

## 🚀 Çalıştırma

Arayüz uygulamasını çalıştırmak için:

```bash
cd goruntu_arayuz
pip install -r requirements.txt
python gorsel_arayuz.py
```
